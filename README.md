# cubedesk-ui-fix

CubeDesk UI fix is a free open-source browser extension that fixes the user interface for CubeDesk on both desktop and mobile devices.

## What's Changed / Features

- **Mobile UI Fixes:** Completely repairs the user interface for mobile devices. Nothing renders off-screen, and all elements are properly aligned.
- **Timer Interaction Fix:** Prevents the browser context/selection pop-up window from showing up when holding down on the timer screen on mobile devices.
- **Desktop Improvements:** Includes light UI tweaks and polish for desktop view.

---

## Installation from Source Code

To install this extension from source code:

1. Download the repository as a ZIP file (click **Code** -> **[Download ZIP](https://github.com/franekk3/cubedesk-ui-fix/archive/refs/heads/main.zip)**) and extract it on your device.
2. Open a Chromium-based browser.
3. Turn on **Developer mode** in the extensions menu (`chrome://extensions`).
4. Select **Load unpacked** (or **Import**) and choose the extracted folder.

---

## Recommended Mobile Browsers

- **[Titanium Browser](https://github.com/jqssun/android-titanium-browser)** *(Recommended)*: A Chromium-based mobile browser with native extension support.
- **[Cromite](https://github.com/uazo/cromite)** *(Alternative)*: Supports extensions as well. 
  > **Note:** During testing on Cromite, the 3D cube model failed to load when connecting a Bluetooth smart cube for unknown reasons.
